# 安全在我心中 · 应急安全文化教育宣传 H5

**作品类别：** 应急安全新媒体作品（宣传 H5 + 在线答题小程序）
**活动主题：** 学安全文化、会应急技能
**适用终端：** 手机、电脑等主流终端（响应式自适应，微信/浏览器直接打开，无需下载安装）

## 一、作品简介

本作品紧扣“学安全文化、会应急技能”主题，聚焦风险隐患识别、应急处置和逃生避险，采用大众喜闻乐见的互动形式普及应急安全知识。作品共设五大板块，将思想引领、知识科普、实战模拟、在线答题融于一体：

1. **首页·思想引领**：宣传贯彻习近平总书记关于安全生产的重要论述，展示“安全第一、预防为主、综合治理”方针及 119、120、12350 等应急电话。
2. **党和人民的守夜人**：展现应急救援队伍在防汛抗洪、抗震救灾、抢险救援、应急值守中“对党忠诚、纪律严明、赴汤蹈火、竭诚为民”的精神风貌，发出全民安全倡议。
3. **应急科普**：火灾逃生、地震避险、燃气安全、用电与触电急救、现场急救（心肺复苏、海姆立克、烧烫伤）、防汛防洪、人员密集场所防踩踏、地铁出行安全 **8 大类场景**，每类配记忆口诀和“应做/禁做”处置要点。
4. **隐患排查实战模拟**：设置家庭厨房、“九小场所”小餐馆、地铁站厅与车厢、人员密集写字楼 **4 个典型场景**，由使用者点选隐患，系统即时判定漏选、误选并逐条讲解，突出隐患识别能力训练。
5. **在线答题闯关**：内置 **38 题权威题库**（单选、判断），覆盖消防、地震、燃气、用电、急救、防汛、防踩踏、城市轨道交通及安全生产法规常识；每局随机抽取 10 题，作答即时反馈解析，结束后给出成绩评级与错题回顾，本机自动记录最佳成绩。

## 二、特色亮点

- **内容导向鲜明**：把重要论述、安全方针与一线应急技能结合，兼具思想性、科普性和社会导向性。
- **突出实战实用**：以“识别隐患—正确处置—逃生避险—现场急救”为主线，学完即可用于生活。
- **城市特色板块**：专设地铁出行安全科普与题库，服务青岛城市轨道交通大客流安全宣传。
- **互动性强**：手风琴科普、场景化隐患判定、随机抽题、成绩评级与错题本，提升学习趣味性。
- **便捷可达**：纯静态网页，一个链接永久访问，更新后刷新即可；适配手机与电脑，支持微信内直接转发分享。

## 三、使用方式

1. 手机或电脑浏览器打开作品链接，无需安装、无需注册。
2. 建议学习路径：首页 → 应急科普 → 隐患排查 → 在线答题，可反复挑战。
3. 可将链接转发至微信群、朋友圈，或生成二维码张贴宣传。

## 四、技术说明

- 纯前端实现（HTML5 + CSS3 + 原生 JavaScript），无后端、无第三方框架依赖。
- 响应式布局，移动端优先并兼容桌面浏览器。
- 答题成绩仅保存在使用者本机浏览器中，不上传任何个人信息。
